COMO ABRIR A ESTAÇÃO iOS NO MAC (leia uma vez)
================================================

O dia a dia: atualizar
-----------------------
Dois cliques em atualizar.command. Ele faz "git pull --ff-only", instala o que
faltar e abre a estação; não mexe no .venv nem nos arquivos de progresso. Se ele
disser que há alteração local ou que não há internet, NADA foi mudado — chame o
suporte em vez de apagar a pasta.

Abrir sem atualizar
--------------------
Dois cliques em iniciar_gui.command.

Instalação, uma vez só
-----------------------
A estação vive num repositório privado no GitHub. Uma vez só, no Terminal:

    cd ~/Trabalho/"Marcelo Queiroz"
    git clone https://github.com/giraor7/iOS-station.git ios-station

(o GitHub vai pedir login: aceite o convite de colaborador que chegou por
e-mail e entre com sua conta; se pedir senha, use um token do GitHub ou faça
login pelo app GitHub Desktop antes).

Se você já tinha uma pasta da estação, copie o .venv dela para dentro da nova:
    cp -R <pasta-antiga>/.venv ios-station/
Se não tiver, o iniciar_gui.command instala sozinho na primeira abertura
(precisa de internet, 1 a 2 minutos).

Daí em diante, cada atualização é só dois cliques em atualizar.command: ele
puxa a versão nova, instala o que faltar e abre a estação. Sem download de zip,
sem quarentena, sem copiar nada.

Se o Mac reclamar do desenvolvedor
------------------------------------
Isso vale para a primeira abertura de uma pasta baixada por fora do git (por
exemplo, se alguém te mandar a pasta por fora do fluxo acima). Tudo que chega
pelo navegador ou por AirDrop recebe a marca "quarentena" do macOS: o Finder diz
que "não é possível verificar o desenvolvedor" ao abrir iniciar_gui.command.
Não é problema no arquivo — é o macOS avisando que veio de fora.

1. Clique com o BOTÃO DIREITO em iniciar_gui.command e escolha "Abrir".
2. Na janela de aviso, clique em "Abrir" de novo.

Isso remove a marca de quarentena da pasta inteira; daí em diante abre com dois
cliques normais.

Alternativa pelo Terminal (mesmo efeito):
    xattr -dr com.apple.quarantine ~/Downloads/ios-station

Arquivos que ficam de fora
----------------------------
Os arquivos progress.scroll.local.json / progress.ios.local.json e qualquer
arquivo de contatos (.csv, .vcf) não vêm no repositório de propósito: eles são
dados pessoais e ficam só neste Mac. Se trocar de pasta, copie-os à mão — ver
COMO-OPERAR.md §8.
